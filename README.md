# 谁在决定我们每天看到什么？

中国传媒大学 2026《马克思主义与社会科学方法论》课程作业
小组成员：蔡琳 / 朱雅婕 / 艾先会 / 熊宇文 / 纵琪

三个专业——**出版、信息通信（大数据）、新闻与传播**——各自从自己的学科视角出发，分析同一个问题：

> 知识的社会价值，如何转化为平台上的可见性？为什么值得被了解的内容，不一定获得更多关注？

## 网页结构

- **开篇**：五个人，五个完全不同的信息世界
- **出版**：什么知识能够成为出版物？（选题会模拟器 · 翻卡交互）
- **信息通信**：什么知识更容易被分发？（推荐算法调参实验台）
- **新闻与传播**：被看见是否等于被理解？（框架切换器 + 责任归因投票）
- **汇合与方法论**：三双眼睛叠成一条链，回到马克思主义社会科学方法论

## 使用

单文件网页，**零依赖、完全离线**。直接用浏览器打开 `index.html` 即可，或部署到任意静态托管（GitHub Pages 等）。
